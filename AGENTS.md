# Codex project: .json immersive memoir

Build a mobile-first companion website for `.json — Jason, under revision`.

## Rules
- Preserve existing manuscript, README, and chapter files. Never overwrite autobiographical text automatically.
- Maintain Jason's natural Vietnamese/Vinglish voice, ages and concrete memories.
- Never invent personal facts. Flag unverified claims and source overlap.
- Do not publish private TikTok videos, messages, names, photographs or identifiable relationship details without approval.
- Credit licensed sources; credit alone does not grant copying permission.
- Keep public pages teaser-first until the author explicitly approves chapter text.
- Use stable chapter slugs independent of changing book chapter numbers.
- Build responsive, accessible pages. No payments or user tracking in the first prototype.

## Preferred stack
Next.js App Router, TypeScript, CSS, local JSON metadata. Deployable to Vercel after testing.

## Workflow
1. Inspect existing repo and docs before changing anything.
2. Make focused pull requests on new branches.
3. Run typecheck and build, report results.
4. Record content source, rights and privacy checks for each published artifact.
5. Make each chapter readable without requiring images, video, audio or buyer login.
